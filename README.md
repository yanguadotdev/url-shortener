# 🔗 URL Shortener

Un acortador de URLs moderno y minimalista, construido con tecnologías de última generación 🚀  

## 🧩 Stack principal
- ⚛️ **Next.js** — framework React para frontend y backend
- 💾 **Turso** — base de datos SQLite distribuida en el edge
- 🧠 **Drizzle ORM** — consultas tipadas y migraciones elegantes
- 🧑‍💻 **TypeScript** — tipado estático para un código más seguro
- 🧾 **Server Actions** — lógica de servidor directamente desde el cliente
- 🎨 **Tailwind CSS** — estilos rápidos y consistentes
- 🪝 **React Hook Form** — manejo de formularios simple y robusto

## ✨ Funcionalidades
- Crear y gestionar enlaces cortos personalizados 🔗  
- Validación de inputs con Zod ✅  
- Slugs únicos generados aleatoriamente 🎲  
- Interfaz limpia y responsive 📱
